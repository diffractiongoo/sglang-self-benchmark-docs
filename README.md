# SGLang self-benchmark documents

Design notes and a worked walkthrough for SGLang self-benchmarking in AISim.

| Document | Description |
| --- | --- |
| [SGLang self-benchmark design](sglang-self-benchmark-design.pdf) | An AISim integration proposal that preserves the vLLM self-benchmark workflow and profile contract through an AISim controller and a narrow SGLang execution adapter. |
| [SGLang self-benchmark journey](sglang-self-benchmark-journey.pdf) | A worked walkthrough of one campaign cell with prefill and decode points, comparing the standalone design with a second design: a driver in the Dynamo worker and a recorder inside the SGLang scheduler. Final version, revised 13 November 2026. It also compares how exposed each design is to SGLang version changes, lists the gaps the second design closes, records a decision for each item that was still open, sets out the AISim launch layer, and ends with seven acceptance checks. The revision replaces the collective RPC hold-and-release route with SGLang's input blocker, because the earlier route reaches only one DP rank under DP attention. |
| [Decode point: vLLM and SGLang](decode-point-vllm-sglang.pdf) | A comparison of how two self-benchmarks run one decode point: the vLLM self-benchmark in Dynamo, and the SGLang self-benchmark as it was built afterwards in AISim, where a launcher sends ordinary generate calls and a recorder in the scheduler process logs the batches. It walks through both procedures step by step and lists where they differ. 4 pages, 16 November 2026. The vLLM side was read from source and not run. The SGLang decode path was run on GPUs on 16 November 2026. No model was run on both. |
| [Decode steps of the SGLang self-benchmark](decode-steps-sglang.pdf) | A short note on why the SGLang self-benchmark in AISim runs six decode steps for one decode point and keeps the median of steps 3 to 5: what the two dropped steps at the start and the one at the end are for, why the last step can be far shorter than the others, and what a run of four steps would give. 3 pages, 16 November 2026. The step times come from a GPU test of 16 November 2026 on one small model. The reason for the short last step was read in SGLang's scheduler at v0.5.22 and v0.5.23 and matched against that test's logs. Runs with a different number of output tokens or with overlap scheduling off were not made. |

Start with the design document, then read the journey for a concrete example. The journey's second design was read from source at SGLang v0.5.22 and v0.5.23. It has not been prototyped or run on a GPU, so the seven acceptance checks are still to do. The decode comparison and the decode steps note describe the SGLang self-benchmark as it was built afterwards, with all of its code in AISim.

Open any PDF to read it in GitHub's viewer, or use the download button to save a copy. This repository contains the four PDF documents; it does not contain the SGLang source code or benchmark artifacts.
